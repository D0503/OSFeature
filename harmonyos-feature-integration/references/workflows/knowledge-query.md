# 知识库查询

使用调用入口指定的完整标题查询 `innovative-feature` 知识库。每个所需标题分别查询。以下命令在包含 `SKILL.md` 的 Skill 根目录执行。

1. 将命令中的标题替换为当前所需标题，搜索候选文档。

   ```text
   node scripts/harmonyos-search-documents.mjs "<完整标题>" --scene-name "innovative-feature"
   ```

2. 从搜索输出的前 10 条中提取有效的 `identifier`，去重后作为文档 ID 一次传给全文脚本。按实际 ID 数量传参，单次最多 10 个。

   ```text
   node scripts/harmonyos-get-documents.mjs "<文档 ID 1>" "<文档 ID 2>"
   ```

3. 在全文输出中核对 `title`。当且仅当一篇文档的标题完全一致且正文非空时，读取其正文，并按下节继续查阅当前任务需要的索引。

请求失败、无候选 ID、无同名文档、有多篇同名文档或匹配文档的正文为空时，说明标题和失败原因，将该资料标记为待核验，并暂停依赖该正文的步骤。

## 续读正文中的索引

取得正文后，沿当前任务所需的相对 Markdown 文档链接继续查询，直到读到所需的正文或章节。

1. 用链接文字中的完整文章标题重新执行上面的查询流程。例如，指向 `arkui-activation.md` 的链接文字为「ArkUI 沉浸光感开启策略」时，在同一知识库检索该标题。
2. 链接带 `#章节` 时，取到文章后定位该章节。链接文字只有章节名时，优先用上下文中的完整文章标题检索。上下文也未给出文章标题时，用章节名搜索并批量取候选详情，只有文档 ID 或 URL 能唯一对应索引路径，且正文包含目标章节时，才采用该文档。仅含锚点的链接直接在当前正文中定位。
3. 在当前任务中记录已读取的文档标题、ID 和已解析的索引目标。重复引用时复用正文，避免循环查询。索引目标无法唯一确认、目标章节缺失，或循环引用后仍未读到所需内容时，指出来源文章和索引目标，按资料待核验处理。
