# 故障排查

| 现象 | 可验证原因与处理 |
|---|---|
| 长按无入口 | 核对目标 Ability 的 metadata、profile 路径、实际安装产物、桌面支持与 visible；不只搜索一个同名 JSON |
| 名称或图标错误 | 核对实际模块与 base 资源、本地化、资源名和图标规范；动态资源模式核对传参是否带错前缀 |
| 点击只到首页 | 快捷方式仅启动 UIAbility；检查 parameters 支持范围、冷暖启动接收、业务映射及导航就绪；保留原鉴权 |
| 暖启动不跳转或重复页面 | 检查 onNewWant 传递、缓存标记消费、窗口与页面生命周期、并发导航；不重建整套首页 |
| 401 | 参数错误；核对重载签名、目标、资源名称或沙箱文件路径，同时核对实际设备是否在接口支持范围内 |
| 1006620001／1006620002 | 系统内部／服务请求错误；核对设备、系统与 AppGallery 服务状态，保留原业务，不自动循环发起请求 |
| 1006620003／1006620004 | ID已存在／达到配额；核对真实桌面状态，需管理时采用API24接口，不自动删旧图标 |
| 1006620005 | 校验失败；比对预置配置与请求的ID、资源名、Want；自定义核对文件格式、大小与沙箱路径 |
| 1006620006 | 事务缺失或过期；清除旧tid并预校验，等待用户再次点击，不自动连续弹框 |
| 1006620007 | 用户拒绝加桌；保持原业务路径和正常拒绝状态 |
| 9001001 | 无效的资源ID（ResourceManager 错误码，非本接口服务错误）；典型触发：HAR、字节码HAR、跨HAP/HSP 模块中 `$r('app.xxx.xxx').id` 为 -1 仍传给 getMediaContent 等按 id 接口，常见于导出沙箱图标。改用按资源名接口（getMediaByName／getMediaContentByName，重载名以本机 SDK 声明为准），不从 `$r().id` 取编号 |
| TV错误／无响应、模拟器服务失败 | 按具体接口设备限制排除动态路线，不以概览服务支持说明覆盖接口限制 |
| 查询不到预期图标 | 区分配置查询与已加桌查询，核对调用应用、真实ID和API24门槛 |
| 删除1006620010／1006620013 | ID不存在／用户拒绝；重新核对列表或保留状态，不用tid作为ID |
| 加了运行if仍编译失败 | 当前SDK不含符号或重载；按所选范围提取资产并核对SDK/compile，不能只靠运行守卫 |

记录错误码、设备和系统、实际入口与参数、构建产物及调用时序，按[兼容性](compatibility.md)、[回退](fallback.md)和[验收](performance-validation.md)定位并回归。不把加桌弹框打开当作最终成功。

完整错误码及各接口的适用范围以[官方 productViewManager API 文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/store-productviewmanager)为准。
