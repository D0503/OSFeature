# 回退与源程序保留

基线为 `pre-integration-source-state`。实施前记录目标页面与普通启动的组件树、布局、控制器、状态、数据、导航、事件生命周期和普通样式；有已有快捷方式或入口时同样记录并保留。

| 条件 | 处理 |
|---|---|
| 旧版本、设备不支持或系统服务不可用 | 不执行新 API，保留原应用入口与业务操作；不生成替代卡片、另一套首页或简化业务 |
| 用户取消、拒绝加桌或删除 | 不自动重试弹框，不改写业务完成状态 |
| tid 过期、目标变化、校验或请求失败 | 失效旧事务；符合条件时重新预校验，等待用户动作 |
| 图标缺失、内容失效或参数未知 | 保留原错误／不可用处理和普通启动路径；不跳转到猜测目标 |
| 可选管理功能版本不足 | 不启用该功能；不影响基础静态或动态业务 |

回退不代表自动卸载、删除用户已有桌面图标或重置业务数据。新增入口在环境不满足时的可见性按原业务策略与确认范围处理；不要把拒绝后显示成功、无界重试或静默删旧入口作为回退。

按[验证](performance-validation.md)在实际低版本／失败环境对照基线；缺少历史基线时记录未知，不反推历史状态。
