## ArkUI 版本保护粒度

按知识库查询流程读取《沉浸光感共享回退与版本保护》的「ArkUI 版本保护粒度」。

静态扫描只能发现版本判断候选，不能证明每个新增调用都被覆盖。API 26 保护检查在需要兼容低版本时标为 `warn`：无论是否匹配到字面量，都须核对常量值、等价比较、Guard 封装、求值顺序及实际调用链。使用值为 26 的常量与直接比较 26 均可，不得仅为匹配静态正则改写等价业务代码或加入审计注释。实施时确认新增调用受保护，并通过目标工程构建与最低兼容版本运行验证；人工核对若确认缺少保护，应报告实际缺陷。

## 回退路径的实测验证

按[通用回退实测](../../../workflows/verification.md#回退路径实测)执行取证与补录；本包专属条件如下。

- 工程 compatible API 低于所选路线门槛（HDS 23、ArkUI 26）时，必须在低版本环境安装本轮构建产物实测：升级接入分支不进入（悬浮样式、材质对象、应用级配置与新增属性调用均不生效），接入前的 Tabs 组件树、侧边/底部响应式布局、栏宽、滚动范围与业务交互逐项保持，无报错崩溃。
- 材质回退（设备不支持、材质关闭）与低版本回退是不同条件：材质回退只回退材质、底部横向布局保持，在达标设备上实测并按 `unsupported`/`disabled` 补录；低版本回退恢复原响应式布局，按 `low-api` 补录。两者不得混用同一份证据。
- “材质观感需实际判图”的要求针对增强效果本身。
