# ArkUI 导航类组件

按[知识库查询流程](../../../../../workflows/knowledge-query.md)读取当前目标对应的知识库正文。

## Navigation 标题栏

读取《ArkUI 沉浸光感 Navigation 标题栏与内容避让》。涉及顶部安全区扩展时，按[共用布局知识](../../../shared/validation.md#窗口沉浸状态与栏间距)核对目标窗口和扩展链。

滚动联动正例仅在用户要求对应交互时使用，放在 API 26 接入分支。复用工程已有的业务内容、状态、主题和 Builder，按标题栏接入要求处理版本保护与逐层安全区扩展。

### 自定义标题高度与内容避让

按[共享标题栏避让规则](../../../shared/validation.md#标题栏内容避让与自定义标题)核对首项遮挡和自定义标题高度。需要搜索区域随滚动收缩时，读取《ArkUI 沉浸光感标题栏滚动联动正例》的「正例一：搜索框标题栏随滚动收缩」。

### 可选：滚动内容切换到标题栏

需要内容标题或分类栏随滚动由标题栏接替显示时，结合标题栏正文的切换规则，读取《ArkUI 沉浸光感标题栏滚动联动正例》的「正例二：内容分类栏滚入标题栏后接替显示」。普通列表内部吸顶沿用其列表布局。

## 原生底部 Tabs

读取《ArkUI 沉浸光感原生悬浮 Tabs》的「选择布局分支」，确认 API 26 的悬浮接入分支及低版本的原布局保留分支。

读取《沉浸光感悬浮 Tab 布局与避让》的「窗口沉浸状态与栏间距」，确定工程的 `floatingBarBottomMargin` 和逐页安全区扩展链。需要扩展时，`Tabs`、链上的 `TabContent` 和自定义组件内部节点也按[共享安全区规则](../../../shared/validation.md#窗口沉浸状态与栏间距)逐一核对；同一节点需要 TOP 和 BOTTOM 时一次传入两者。

若用户决定 Tab 页面同时延伸顶部和底部系统安全区，按该节提醒使用 HDS 底部 Tab，并说明 ArkUI 在 `barBottomMargin: 0` 与 TOP、BOTTOM 同时扩展时仍额外抬高 28vp 的已反馈现象，由用户确认路线。

确认原生 Tabs 路线后，按同一篇原生悬浮 Tabs 正文配置悬浮栏和材质。示例中的 `this.floatingBarBottomMargin` 使用上一步确认的工程配置值。

### 悬浮分支的页签切换动画

按原生悬浮 Tabs 正文的「栏宽、断点与切换动画」处理原有 `.animation(...)`。

### 悬浮 TabBar 栏宽与断点

结合原生悬浮 Tabs 正文，按[共享栏宽与断点规则](../../../shared/validation.md#悬浮-tab-栏宽与断点)核对接入分支。

### 普通与悬浮分支的外层 padding

定位《沉浸光感悬浮 Tab 布局与避让》的「普通与悬浮 Tab 的外层避让」，核对原有 `windowBottomPadding` 的用途、布局层级和生效分支。

### 可滚动 Tab 页尾部避让

定位《沉浸光感悬浮 Tab 布局与避让》的「悬浮 Tab 的滚动尾部避让」，逐页核对真实滚动容器和补偿位置，再按同篇「布局验收标准」和[共享验收](../../../shared/validation.md#共享验收标准)验证。
