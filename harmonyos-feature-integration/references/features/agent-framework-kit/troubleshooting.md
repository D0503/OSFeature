# Function 拉起排障

先记录目标页、运行 API、设备类型、应用/元服务类型、组件配置和错误码；只读取必要的签名身份信息，不输出密钥。核对[前置操作](prerequisites.md)，不能以构建通过代替平台可用。

| 现象 / 错误码 | 检查与处理 |
|---|---|
| 1022400010 参数错误 | agentId 是否真实且为 1–64 字符、context 是否 UIAbilityContext、配置类型与范围是否正确 |
| 1022400011 隐私协议未授权 | 由用户主动点击 Function 入口，在小艺页面同意协议；查询失败不能永久隐藏授权入口 |
| 1022400012 未登录华为账号 | 在测试设备登录正确华为账号，核对测试白名单，再查询/点击 |
| 1022400013 网络错误 | 核对网络或弱网状态，恢复后重试，保留原业务 |
| 1022400014 内部错误 | 核对内部连接及小艺版本，可由开发者通过应用市场更新小艺后复测 |
| Agent 未授权给该应用 | 核对关联关系、应用名称、包名、appid；自动签名身份不一致时使用手动签名；修改关联后重新发布测试 |
| 没有 Function 入口 | 核对实际集成、API 20/21、设备/SysCap、页面条件分支；检查是否把所有查询异常都当 false |
| 小艺可见测试 Agent，应用不能拉起 | 核对小艺至少 11.3.8.300、测试账号、关联与签名身份 |
| 修改参数后仍拉起旧 Agent/旧意图 | 参数只初始化一次，销毁重建并隔离旧查询、旧监听 |
| 正式发布后仍显示“开发中” | 白名单账号优先拉起测试版，由开发者取消测试发布或调整白名单 |
| 测试版消失 | 核对 15 天有效期、最后一次发布的用户组与设备账号 |
| 返回页面后回调重复 | 检查 on/off 是否同一 controller 和 callback，可见生命周期是否重复订阅 |

`onError` 文档列出的组件回调错误为 1022400010、1022400014；`isAgentSupport` 还可能返回 1022400011–13。不要承诺所有错误都经组件 onError 上报。1022420001 等其他模块错误不作为 Function 专属接入规则。

修复后回归点击、打开、关闭、原状态保留及对应负向场景；模拟器与无法确认的设备不能判定该特性运行通过。
