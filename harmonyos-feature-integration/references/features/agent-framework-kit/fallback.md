# 回退与源程序状态

基线为 `pre-integration-source-state`。新能力只在已满足版本、设备及服务条件的分支执行。

- 系统版本不足、SysCap 不支持或非支持设备：不创建控制器、不构建 Function 组件、不调用查询及 on/off，继续原组件和业务路径。
- 入口是新增时：不可用分支不保留空白占位或额外边距；原布局不受影响。
- 入口替换已有业务操作时：仅在用户确认替换方式后实施，保留原操作的代码、数据、事件和导航路径，失败不改变原业务结果。
- 查询 false、账号/网络异常或服务不可用时：保留原路径与业务状态。隐私待授权单独处理，不能永久封死用户主动授权入口，详见[实施](implementation.md)。
- 页面消失或重新实例化：只取消本实例订阅，忽略迟到查询结果。回到页面可恢复查询，不重复打开对话框。

对照接入前后检查组件树、横竖屏及窗口布局、主题样式、原点击行为、焦点、状态/数据、控制器和生命周期。不要为不可用环境生成新的低配聊天页、替代智能体或新的账号登录流程。
