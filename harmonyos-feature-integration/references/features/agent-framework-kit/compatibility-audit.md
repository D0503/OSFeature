# 智能体框架服务扫描与回退

按[共享工作流](../../workflows/compatibility-audit.md)逐调用核对 SDK @since、运行版本与能力条件，包含 Function 组件、控制器、枚举、初始化、查询、on/off 和封装调用链。

版本或能力不满足时隐藏拉起按钮，不创建 Function 组件、不执行相关调用，保留其他页面操作。若是该业务唯一入口，先询问是否接受低版本业务不可达，再修改。已有回退优先复用，保留状态和一多布局。

高版本按本能力包 Phone/Tablet 真机要求验证点击、拉起及关闭，不能以按钮显示代替成功；低版本验证隐藏及无不支持的初始化和清理调用。
