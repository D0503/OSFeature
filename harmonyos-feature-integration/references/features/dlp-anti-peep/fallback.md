# 回退

运行版本不足、设备无能力、ACL未获准、开关关闭或服务异常时沿用接入前的页面、数据、状态、交互及原有保护行为；不增加“已保护”标记，不把失败改成 PASS，不默认放通。

API20状态能力不支持系统蒙层；API21系统蒙层不支持API23设置弹框。仅有用户已选择的低版本路线时保留该路线，不能为了“降级”自行新增自定义遮罩。按页面生命周期取消本次订阅，不再更新已销毁组件或对失效窗口调用蒙层。

## 回退路径的实测验证

按[通用回退实测](../../workflows/verification.md#回退路径实测)执行取证与补录；本包专属条件如下。

- 工程 compatible API 低于所选路线门槛（状态感知 20、系统蒙层 21、设置弹框 23）时，必须在低版本环境安装本轮构建产物实测：订阅、蒙层、设置弹框等增强不生效，接入前页面、数据、状态、交互与原有保护行为保持，无报错崩溃，不默认放通、不显示“已保护”标记。
- “防窥效果只接受已确认的 Phone 真机证据”针对蒙层与状态的实际表现；低版本回退实测验证“增强不启用、源基线保持”，不依赖传感器检测。
- ACL 未获准、开关关闭、服务异常在达标环境按[兼容性](compatibility.md)触发方式实测，分别以对应 condition 补录。
