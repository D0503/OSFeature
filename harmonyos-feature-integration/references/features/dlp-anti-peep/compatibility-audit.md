# 防窥保护扫描与回退

按[共享工作流](../../workflows/compatibility-audit.md)分别核对状态感知、系统蒙层、设置及风险提示接口的 SDK @since、版本和能力守卫，包括枚举访问、初始化及 on/off。

不支持时不查询、不订阅、不执行对应蒙层及清理调用，沿用普通业务展示。不新增遮罩、不额外隐藏敏感内容；工程已有的普通展示规则保留。未知、不支持或查询失败不标记为“已确认安全”。

防窥设置等独立入口每次改造询问隐藏或保留并 Toast 提示不支持；同次相同场景复用选择。高版本遵循能力包 Phone 真机要求验证防窥响应和蒙层，低版本验证普通展示、入口选择及无不支持调用。
