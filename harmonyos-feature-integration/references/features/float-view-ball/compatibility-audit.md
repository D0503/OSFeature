# 闪控窗／球扫描与回退

按[共享工作流](../../workflows/compatibility-audit.md)分别核对窗、球、绑定的 SDK @since 和能力条件，覆盖创建、启动、更新、停止、销毁、查询、订阅/取消订阅、枚举、对象和初始化；保护启动入口不能代替完整保护。

不支持时不创建/启动对应功能，保留应用内页面和业务。绑定不可用不自动禁止两端独立能力，两端分别判断。不自行新增普通悬浮窗、自绘球或画中画替代。

每次工程改造都询问相关独立入口：隐藏，或保留并 Toast 提示“当前系统或设备不支持闪控窗/闪控球/窗球绑定”。同次相同场景复用选择，不跨工程设默认值。原按钮同时承载业务时保留原行为，仅对无法执行的闪控操作提示；唯一业务入口影响另行确认。

高版本按能力包设备要求验证完整启动、交互、更新、关闭及绑定；低版本验证入口选择、应用内业务和退出清理均不触发不支持调用。
