# 排障

| 现象 | 证据与处理 |
|---|---|
| 201 权限失败 | 核对实际宿主声明、FLOAT_VIEW 与 USE_FLOAT_BALL 的 ACL、签名身份及 FLOAT_VIEW 用户授权；绑定要求两者 |
| 801 不支持 | 检查运行 API、设备/窗口模式、SysCap及 enabled 查询，不只看编译通过 |
| 1300033 或启动冲突 | 核对同应用已有窗、球、画中画与前台状态，等待实际停止完成 |
| 1300016 页面/参数错误 | 对照 pages profile、加载方式、尺寸单位px和限制 |
| 窗页面顶部内容被遮挡或预留异常 | 核对页面根容器 top padding 是否按形态设置：常规态（ROUNDED_RECTANGLE）32vp、mini 态（HORIZONTAL_BAR）4vp，并确认随模板切换同步；再核对 avoidArea 实际值 |
| 窗尺寸未随屏幕尺寸变化更新 | 先确认原工程是否已有断点或屏幕尺寸响应机制：有则核对接入与重算链路（借用状态、当前模板限制、vp 转 px 收敛）；无则属预期行为，不为窗单独新增监听 |
| 恢复主窗失败 | 球核对可选 Want 和真实包名／Ability；窗核对用户点击来源、STARTED、主窗口生命周期及 wantParameters。回调执行不表示恢复成功，查看 restoreMainWindow 日志 |
| await 操作后状态仍未变化 | 窗球控制器资产异步操作返回 Promise，启动完成仍以 STARTED 为准，停止完成以 STOPPED 为准 |
| 重复回调或启动失败后仍有监听 | 窗球资产均在创建控制器后注册监听。两条路线均需处理准备／启动失败的退订，重试前清理本次实例监听 |
| 绑定操作被拒绝 | 核对组合方法调用顺序及已有独立实例，业务入口避免重复点击和并发调用；两端未完成 STOPPED 时不能解绑，停止 Promise 完成不能代替终态 |
| 绑定切换后异常 | 核对 bind 时均未启动、只启动一端、未把 IN_FLOATING_BALL 当停止 |

任务范围按[通用排障](../../workflows/troubleshooting.md)执行；修复后重跑对应路线与绑定场景。

## 闪控球错误码

| 现象／错误码 | 检查重点 |
|---|---|
| 201 | 宿主 USE_FLOAT_BALL 声明、ACL 批准及实际签名 profile |
| 801 | 系统版本、设备和 Tablet 模式；不以枚举的设备标签推断接口可用 |
| 1300019 | 模板与空标题、UTF-8 字节超限、PixelMap 像素字节数、颜色格式及增强参数条件 |
| 1300021／1300022 | 同应用多球或重复操作，检查创建和启动是否串行 |
| 1300024／1300025 | 控制器或球状态不支持当前操作，检查停止后仍更新等时序 |
| 1300026 | 恢复主窗口的包名、目标 Want、用户点击条件和额外权限 |
| 1300027／1300028 | 更新时修改了 template，或试图更新 STATIC |
| 1300034（API26+） | 与已有闪控窗冲突，核对是否采用正确绑定／停止流程 |

## 闪控窗排查

| 现象 | 检查重点 |
|---|---|
| 权限失败 | 宿主 FLOAT_VIEW 声明、reason 资源、ACL、实际签名 profile 和用户授权 |
| 不支持或能力检测失败 | API26、SysCap、设备与窗口模式、isFloatViewEnabled；失败保留原业务 |
| 空窗或页面加载失败 | pages profile 路径、页面资源、加载完成后才 start |
| 尺寸不符 | px 单位、当前模板尺寸与比例约束、onRectChange 实际结果 |
| mini 态内容偏下或贴底、顶部留白过大 | 内容行写了固定高度且贴顶排布：系统按横条模板约束调整后的实际窗口高度可能小于请求值，固定行高底部溢出裁剪，行内居中的内容被挤到窗口底部（对比请求尺寸与 onRectChange 实际矩形、量 UI 树内容行与窗口根节点上下空白可复核）。修复：去掉内容行固定 height，由内容自适应，垂直位置交给根容器 `justifyContent(FlexAlign.Center)` |
| 重复窗口或启动冲突 | 创建入口并发、应用前台、已有窗／球／画中画是否已结束 |
| 恢复失败 | 用户点击来源、STARTED 状态、主窗口生命周期及参数类型 |
| 停止后仍有回调 | 配对退订状态、限制及自行添加的矩形监听，清理业务订阅 |
