# 兼容性与权限

通过 `MCPXX` 查询关键词 `闪控球／窗兼容性与权限`，读取同名知识条目的正文。按当前路线核对编译与运行 API、设备与模拟器支持、ACL 与授权、签名要求和启动限制。查询未取得正文时，标记兼容性资料待核验，并暂停依赖这些资料的工程改动。

版本升级遵循[通用兼容性规则](../../shared/compatibility-model.md#升级接入对所有特性通用)。

## 权限声明、ACL 与用户授权

首次修改工程前及实施结束后的最终交付中，均根据查询结果提醒开发者核对本次路线所需的受限 ACL 权限、窗的用户授权条件和实际签名状态，并提供知识条目中的 ACL 申请链接。实施前已提醒不能省略实施后的提醒；声明或静态检查通过不能证明 ACL 已获准或用户已授权。Skill 提供操作指引，不代替平台审批，不索取签名私钥。

接入后需要重新签名；本地调试使用自动签名时，同意本次权限申请，并核对更新后的签名 profile 包含所需权限。
