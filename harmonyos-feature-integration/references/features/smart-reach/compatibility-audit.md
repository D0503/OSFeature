# 智感握姿扫描与回退

按[共享工作流](../../workflows/compatibility-audit.md)核对组件适配属性、操作手/握持手查询及订阅/取消订阅的实际 SDK @since。单独出现 HdsTabs 不是接入证据。

低版本不执行不支持的属性、查询、注册和注销；沿用基础布局和位置，保留全部入口。撤销仅由握姿引入的按钮移动及排列调整，保留断点、横竖屏和窗口适配。没有原始布局时参考已有默认布局，左右选择无法确定且影响业务时询问。

与沉浸光感分别判断，不互相撤销。高版本效果必须真机验证并引导用户完成握姿动作；低版本验证基础操作、布局及页面退出清理，模拟器不证明握姿效果。
