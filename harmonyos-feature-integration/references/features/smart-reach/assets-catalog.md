# 资产目录

| 路线 | 最小资产 | 使用方式 |
|---|---|---|
| 系统组件原生适配（如 HDS） | [HdsTabs 属性片段](routes/native-component/assets.md) | 合并到实际 HdsTabs，保留控制器、内容、事件和原分支 |
| 操作手 | [接入说明](routes/operating-hand/assets.md) | 按实际页面组织状态查询或事件监听 |
| 握持手 | [接入说明](routes/holding-hand/assets.md) | 按实际页面组织握持手监听与组件位置状态 |

算法测试可以模拟动作与异常；必须在用户工程编译和支持真机验证后才能标注已验证。
