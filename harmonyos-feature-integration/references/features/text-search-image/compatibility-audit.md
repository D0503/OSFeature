# 已接入文搜图的低版本回退方案

适用于已经接入 `textSearchImage`、仍支持安装到 HarmonyOS `26.0.0` 以下手机的工程。按实际构建的 product 核对 `compatibleSdkVersion` 和 SDK 中所用接口的 `@since`。保留原最低兼容版本及配置格式。扫描和修复步骤见[共享兼容性工作流](../../workflows/compatibility-audit.md)。

## 运行时保护

复用已有等价守卫。使用 API 26 SDK 编译时，在首次访问 Kit 前用 `deviceInfo.apiAvailable('26.0.0')` 检查运行版本，通过后再检查 `canIUse('SystemCapability.AI.Vision.VisionBase')`。沿服务封装和真实调用链检查模块与页面初始化、自动建库、搜索、图片变更、清库重建和退出清理。低版本上六个接口 `init`、`insertImage`、`search`、`deleteImage`、`clearData`、`release` 均不可达；高版本只有初始化成功的会话才提交操作和释放。可对照[会话资产](assets/TextSearchImageSession.ets)复核守卫位置。

## 低版本业务行为建议

优先沿用工程已有的回退约定。以下做法供开发者按业务场景选择。现有约定不明确，且选择会影响入口、交互或数据行为时，可以询问开发者。

| 已接入位置 | 建议做法 |
|---|---|
| 文搜图嵌在原搜索中 | 可让原有搜索框、查询和结果展示继续工作。只有浏览能力的页面可沿用原浏览、预览与导航流程。 |
| 独立文搜图入口 | 可隐藏入口，或保留入口并在点击时提示当前系统版本不支持。 |
| 图片导入、删除或页面退出 | 可沿用工程原有的图片导入、删除、预览和退出流程。 |

选定方案后，对照[回退基线](README.md#回退基线)核对数据、布局和交互。结果和空态可沿用工程既有的展示方式。

## 验收

- 将本轮同一构建产物安装到低于 `26.0.0` 且满足工程最低兼容版本的手机，按选定方案验收启动和进入图库、原搜索或浏览、独立入口、图片变更、退出再进入等适用场景。用日志和调用链复核六个 Kit 接口均未触发，并保留低版本截图及设备版本。
- 在支持文搜图的 `26.0.0+` 真机回归初始化、入库、检索和释放，以及实际接入的删除或重建操作。按[验收场景](validation.md#验收)记录两端结果。
