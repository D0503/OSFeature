# 验收与排障

## 验收

先用 `check-compatibility.mjs` 检查工程门槛、`verify-integration.mjs` 核对实际调用及入口，再用 `verify-development.mjs` 构建目标 product。效果验收用已确认的 API 26.0.0+ Phone、Tablet 或 PC/2in1 真机，记录设备形态、运行版本、地区与 SysCap。

| 场景 | 核对证据 |
|---|---|
| 入库并检索 `index-and-search` | 使用非敏感测试图片。分别在两个作用域入库，用中文描述检索，核对相关图片可打开、作用域隔离、数量上限、相似度和合法零结果。若启用了排序，核对应用侧降序。 |
| Picker 导入 | 涉及选图时，覆盖取消、正常图片导入、尺寸越界和复制失败。核对最终路径为可读的应用沙箱路径，失败时临时文件得到清理且该图片未提交入库。若启用了转码，用目标格式和超限样本验证实际输出及检索结果。 |
| 重启与中断恢复 | 涉及持久化时，入库后重启应用或覆盖安装，用同一作用域重新搜索并打开命中图片。模拟记录已落盘但入库未完成、Kit 已写入但状态未落盘，验证待入库记录能恢复，失败项可定位，界面状态与实际检索结果一致。 |
| 生命周期 | 快速切换查询与作用域、建库期间发起查询、退出后重进。核对 Kit 调用串行、失败后队列可继续、过期回调不覆盖界面、退出释放结果得到处理。记录重进后的实际索引状态。 |
| 删除与恢复 | 涉及索引删除时，核对索引记录消失及源图管理行为；涉及全库恢复时，模拟能力更新，并在隔离测试图库上覆盖清除返回 false、抛错、成功后跨作用域重建与重建中断。 |
| 回退 `source-state-fallback` | 工程支持低于 API 26 的系统时，在低版本设备验证旧入口、原业务及无新调用。支持机覆盖初始化 false 或抛错、图源无效及功能关闭等适用分支。对照原搜索、浏览、数据和既有异常行为。 |

运行判定至少为 `index-and-search` 与 `source-state-fallback` 各提交一条观察，关联本轮运行日志或组件树证据。适用的低版本回退另附设备信息、构建标识及回退截图按共享流程补录。用截图补充展示结果，日志避免记录真实查询词、完整业务路径或用户图片内容。

## 故障排查

| 现象／错误 | 定位与处理 |
|---|---|
| `init` 返回 false 或抛错 | 分开记录。查真机、运行版本、地区、SysCap 和前一会话是否收尾。保留接入前流程，等待服务可用后再尝试。 |
| `401` 参数错误 | 对照当前 SDK 与 API 参数表复查路径、scope、query 和 topKey。用字母数字 scope 与中文查询逐一排除。 |
| `1013100001` 图像不可用 | 在 `insertImage` 中检查真实沙箱路径、读权限、文件存在与两边像素尺寸，修正后重试该图片。 |
| `1013100002` 服务异常 | 六个方法均可能遇到。记录方法和失败类型，检查同进程并发、其他服务占用及生命周期竞争。恢复后按业务重试，保留失败项。 |
| `1013100003` 能力已更新 | `insertImage` 或 `search` 进入[全库重建流程](implementation.md#模型更新与全库重建)。等待清除与目标作用域重建成功后再查询。 |
| 结果为空、错组或图片打不开 | 核对每张入库的成功状态、scope、topKey、查询有效性及返回路径当前是否可读，必要时换一组已知图文样本复测。 |

错误码依据见[华为 Core Vision Kit 错误码](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/errorcode-core-vision)。
