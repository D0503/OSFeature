# 文字搜索图片

华为开发指南称为「通过文本搜索图片」，也称「文搜图」。以中文描述检索已为应用建立索引的沙箱图片，返回路径、作用域和相似度。适合应用内相册、聊天历史图片或商品图片检索。OCR、图片生成、以图搜图、系统图库全量检索和云端图库检索分别使用对应方案。

接入路线 `core-vision-text-search-image` 使用 Core Vision Kit 的 `textSearchImage`，接到工程已有的图片数据与搜索入口。

## 回退基线

接入前记录原图片来源、搜索或浏览入口、结果与空态、加载和异常行为、路由、布局与数据所有权。低版本、设备不支持、开关关闭、图源拒绝或取消、服务失败或等待重建时，继续原搜索或浏览流程，保留原图、组件树、布局、样式及现有状态和交互。检索失败、旧查询回调或索引未就绪时，按原业务反馈处理，避免覆盖有效结果或把服务故障显示为零匹配。验收按实际接入位置逐项对照。
