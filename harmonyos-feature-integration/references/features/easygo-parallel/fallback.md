# 回退与源程序保留

基线为 `pre-integration-source-state`。保存原组件树、路由栈及参数、控制器/状态、数据、事件、生命周期、窗口方向和断点布局。未启用平行视界时继续原路径，不新增“简化单栏版”。

| 条件 | 必须核对 |
|---|---|
| 低于配置或调用所需 API | 不调用高版本接口；高版本 JSON 字段在旧系统的具体处理须实测，不编造忽略规则；旧版导航、参数、页面与业务保持可用 |
| 窗口尺寸不满足、折叠收起、自由多窗或设备不支持 | 原单页布局及交互保持；不清空栈、不重置表单或滚动状态 |
| 用户关闭系统特性或对应模式配置 original | 回到原应用体验，不能仅以材质/背景恢复代替行为验证 |
| 进入全屏页、方向变化或退出分栏 | 页面返回顺序、参数和数据保持；虚拟容器变化不引入尺寸缓存错误 |

新增监听必须退出时清理，新增窗口方向请求结束后恢复原策略。对未覆盖设备明确写未验证；没有额外权限请求时将“权限拒绝”标为不适用并说明依据，不制造授权流程。

## 回退路径的实测验证

按[通用回退实测](../../workflows/verification.md#回退路径实测)执行取证与补录；本包专属条件如下。

- 工程 compatible API 低于所选配置/调用门槛（基础 23，增强字段 24/26）时，必须在低版本环境安装本轮构建产物实测：不调用高版本接口，未启用分栏的原单页导航、路由栈、参数、页面与业务保持可用；`easy_go.json` 高版本字段在旧系统的实际处理须实测确认，不编造忽略规则。
- 窗口尺寸不满足、折叠收起、系统关闭特性或配置 original 的回退在达标设备上按各自触发方式实测，分别以 `unsupported`/`disabled` 补录；不把“回到单栏”的任一证据复用为低版本回退结论。
- 分栏触发与联动场景按能力包设备要求另行验证。
