# 图像超分扫描与回退

按[共享工作流](../../workflows/compatibility-audit.md)核对已接入工程的最低兼容版本。若 `compatibleSdkVersion` 低于 `26.0.0`，在现有超分路径入口加 `deviceInfo.apiAvailable('26.0.0')` 判断，复用已有等价保护，不提高最低兼容版本。判断要覆盖初始化、处理和退出清理，不能只挡按钮点击；已有 SysCap 检查仍保留。

低版本只跳过超分，保留原图和原有图片业务。按实际触发方式沿用工程已有的不可用策略；若需改变用户可见行为且没有既定策略，先确认。例如，独立超分按钮可禁用并说明原因，自动处理流程则可跳过超分并继续后续步骤。

低版本验证入口处理符合约定、原业务正常且不触发超分调用；高版本按[验收方案](validation.md#验收)验证原有超分功能。
