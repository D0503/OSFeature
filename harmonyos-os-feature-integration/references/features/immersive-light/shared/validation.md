# 沉浸光感共享性能、降级与验证

本文件只维护 HDS 与 ArkUI 共用规则。选中路线后继续读取对应 `routes/<route>/validation.md`，组合路线两份都读。

## 共享降级要求

所有回退条件都以[接入前源程序状态](fallback.md)为基线。普通背景、边框或阴影只是视觉维度，不能替代组件树、布局、状态、数据、交互、生命周期和异常路径。

- API、设备能力或系统状态不满足时，不把材质作为业务状态的唯一表达；
- Web 同层渲染出现透明等异常时，关闭目标控件材质或相关同层能力，并保留源行为；
- 一个路线回退不自动禁止另一个已满足条件的路线；
- 任何新增尾部留白、布局偏移和应用配置都只进入需要它的增强分支。

## 共享性能红线

1. 不给整页或超大背景设置材质，优先限制在卡片、工具栏、悬浮按钮等局部区域。
2. 不在父子节点重复嵌套材质，不给大量列表项分别设置材质。
3. 不叠加重复背景模糊、背景效果和多重阴影。
4. 不把材质覆盖在视频、动图等持续变化内容上。
5. 避免持续修改材质区域尺寸、位置、透明度、参数或子树结构。
6. 避免无限循环动画；Dialog/Menu 等空间动效控制面积。
7. 不在大量文本和图标的整棵子树上开启自动反色。

## 共享测试矩阵

- 工程最低支持版本、API 23 和 API 26 中与选中路线有关的节点；
- 高、中、低算力设备；
- 系统沉浸光感“强、均衡、弱”档位；
- 深色和浅色模式；
- 材质支持、不支持、关闭三类结果；
- 动态背景、滚动内容、弹窗和持续动画场景；
- 接入前源程序回退路径；
- 组合路线中 HDS、ArkUI 各自成功以及单边回退的组合。

## 悬浮 Tab 的滚动尾部避让

该规则同时适用于 HDS `HdsTabs` 和 ArkUI 原生 `Tabs`：只要悬浮栏通过 `barOverlap(true)` 覆盖内容，就逐个检查每个 Tab 页中的 `List`、`Scroll`、`WaterFlow`、可滚动 `Grid` 和自定义滚动容器。最后一个可操作项及其点击、拖拽或手势热区必须能够完整滚动到悬浮栏上方。

- 在最后一个真实滚动项之后增加按实际遮挡高度计算的尾部空间；不要使用固定通用值；
- `List` 可使用 `contentEndOffset` 或尾部占位项，`Scroll + Column` 可使用末尾 `Blank`、内容容器 bottom padding 或等价实现；
- 尾部空间只负责滚动内容防遮挡，不替代决定悬浮栏位置的外层 padding、系统安全区或栏外边距；同一段安全区高度不得重复计算；
- 仅在实际渲染为悬浮重叠布局的分支启用补偿。低版本、设备不支持或业务关闭材质的路径如果已经恢复为普通非悬浮 Tabs，则继续保留接入前的滚动范围和 padding；如果仍使用 `barOverlap(true)` 的普通样式悬浮栏，仍需尾部避让；
- 无滚动内容的 Tab 页不增加空白；所有 Tab 页逐页验证，不能只检查默认页。

## 共享验收标准

- 本机 SDK、工程 API、Stage/module 和设备上下文有文件证据；
- `selectedRoutes` 与工程真实组件体系一致；
- 每条选中路线只使用自己的接口、门禁和资料；
- 旧版本、不支持、禁用或外部条件不满足时保留接入前源程序状态；
- HDS 或 ArkUI 悬浮 Tabs 的每个可滚动页面都能让最后一个可操作项完整滚到悬浮栏上方；
- 没有明显的大面积、嵌套、动态背景或无限动画风险；
- 静态检查、真实构建、真机验证和未完成项分层报告；
- 组合路线分别给出结果，不以一条路线的成功替代另一条。
