# 验证与性能

## 静态与构建

运行 `node scripts/verify-integration.mjs --project <工程> --feature easygo-parallel --route router|navigation --sdk <SDK>`（router|navigation 表示二选一）。检查 entry 引用的实际 JSON、配置结构、API 门槛、设备覆盖、路由冲突、页面引用与互斥关系。未解析动态页面和 id 归属保持 warn；源码文字匹配不证明运行正确。

使用通用 verify-development.mjs，`--feature easygo-parallel`、明确 `--route`，其余构建/设备/导航/证据参数保持不变。改造记录的 category 写“导航模式”或“购物模式”，effect 写已实施配置和目标跳转；不能写成已观察到的效果。

## 运行矩阵

| 场景 | 验收行为 |
|---|---|
| 宽屏与方形窗口 | 分别检查至少 600vp 的条件与长宽比边界，配置对应生效；不能仅看设备名称 |
| 导航模式 | 左侧主页保留，右侧跳转正确；配置 pagePairs 时逐对检查来源/目标和通配目标 |
| 购物模式（API 26） | 右侧栈顶向左推入，左侧次栈顶；返回栈与参数正确 |
| 启动流程全屏页 | 冷启动检查开屏广告、启动页、首次隐私协议页不参与分栏；检查广告结束/跳过、协议同意/拒绝后的既有流程，以及进入业务页后的分栏表现。没有独立路由的弹窗/启动图按原行为验证，不宣称已通过 fullScreenPages 控制 |
| 关联/过渡/全屏页 | 关联页无参数可初始化；过渡页不右推左；全屏页退出分栏并可正确返回 |
| 横竖屏、展开/收起 | 不重置业务状态；supportLandscapeFullscreen 行为符合配置 |
| 虚拟容器及比例拖拽 | 页面实际宽度、断点、lpx、drawableRect 与配置相符；不能统一按整窗一半算 |
| 弹窗与深浅色 | 右侧或居中位置正确，分割线颜色正确 |
| 窗口分屏/自由多窗 | API 26 开关和尺寸决定分屏表现；自由多窗不宣称支持 |
| 低版本/关闭/不支持 | 对照 [回退基线](fallback.md)，原布局、栈、参数和业务行为保留 |

每种实际覆盖场景记录设备、系统、窗口/开关、操作序列、目标页截图与运行证据。API 24+ 可用 isEasySplit 辅助确认状态，但不能代替视觉与交互检查；API 23 用真实页面和组件树验证。

左右页面同时可见时观察帧率、内存、重复请求、监听和节点实例，优先复用工程已有性能工具；不捏造固定阈值或把模拟器结果当真机验收。没有设备时只报告静态/构建结果和待验证场景。
