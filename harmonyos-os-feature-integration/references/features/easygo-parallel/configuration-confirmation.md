# 配置确认

在工程扫描后、写入配置前使用本流程。用户只说“接入平行视界”时，先展示配置清单，再集中确认业务选择；不能直接套用模板完成接入。用户已明确的配置和已授权的选择直接沿用，不重复提问。

## 准备候选与清单

读取真实页面表、路由映射、页面内容和调用链，整理“页面用途＋实际路由标识＋证据位置”。Router 使用所属模块 pages 中的路径；Navigation 区分 navBar 和实际目的页 name。常量或动态名称需继续追踪，无法确定时标记待核实，不编造名称，也不要求用户自行查代码。页面用途用业务语言解释，但不能仅凭名称把某页自动加入全屏页或过渡页。

按所选技术路线、交互模式及当前/拟升级 API 展示下表中的适用项目。当前值须从目标设备配置读取；phone/tablet 完整替代 common，不能把 common 的值当作设备覆盖中已有的值。建议值与已确认值分列。版本暂不支持的项目注明升级要求；无需对不适用项提问。

| 配置项 | 用途 | 最低 API / 适用范围 | 当前值 | 建议值或候选 | 待确认内容 |
|---|---|---|---|---|---|
| common / phone / tablet | 设备范围及覆盖 | 23 | 按工程填写 | 按目标设备提出配置范围 | 哪些设备启用或保留 original |
| wideWindowMode / squareWindowMode | 宽屏、方形窗口行为 | 23 | 按工程填写 | 所选路线的 Split 或 original | 哪些窗口启用 |
| routerSplitOptions / navigationSplitOptions | 技术路线 | 23，互斥 | 按工程填写 | 沿用真实导航体系 | 仅确认尚未明确的路线 |
| mode | 导航/购物模式 | 显式字段需 26 | 按工程填写 | 说明两种行为并结合业务建议；API 23～25 不写 mode | 选择交互模式，涉及升级则同时确认 |
| homePage | 左侧主页 | 23 | 按工程填写 | 真实首页/目的页候选 | 主页用途与标识是否符合需求 |
| relatedPage | 主页的关联页 | 23，需 homePage | 按工程填写 | 无动态参数也可初始化的真实页面候选 | 配置哪页，或明确无需关联页 |
| fullScreenPages | 进入这些页面后退出分栏 | 23 | 按工程填写 | 已核实的开屏广告页、启动页、隐私协议页默认纳入；列出其他真实页面候选 | 仅确认其他未明确页面、明确例外或配置冲突 |
| transPages | 固定右侧、不向左推入的页面 | 26，仅购物模式 | 按工程填写 | 真实编辑等页面候选，说明 DIALOG 默认过渡行为 | 哪些页作为过渡页，或明确无需额外过渡页 |
| enableReducedContainerSize | 虚拟容器尺寸换算 | 23 | 按工程填写 | 新接入 true | 若现有值或用户选择为 false，保留并说明差异 |
| drawableRectHook | drawableRect 页面级尺寸换算 | 26 | 按工程填写 | 新接入 true；低版本需升级，否则省略 | 升级选择或显式 false 的差异 |
| supportLandscapeFullscreen | 主动横屏时是否退出分栏 | 23 | 按工程填写 | 沿用已有值；未配置建议 true | 可整体接受建议或指定修改 |
| dialogSupportSplit | 弹窗在右半屏或居中 | 23 | 按工程填写 | 沿用已有值；未配置建议 true | 可整体接受建议或指定修改 |
| homeNavigationId | 全局路由容器 | 23，仅 Navigation | 按工程填写 | 复用已核实容器 id；需要新增时说明目标 | 容器无法唯一确定时确认用途 |
| disablePlaceholder / disableDivider | 隐藏占位页/分割线 | 23，仅 Navigation | 按工程填写 | 沿用已有值；未配置建议 false | 可整体接受建议或指定修改 |
| pagePairs | 触发分栏的 from/to 关系 | 26，仅导航模式 | 按工程填写 | 根据真实跳转关系建议；无需特殊配对时省略 | 是否指定配对及对应页面 |
| wideSplit / squareSplit | 比例与拖拽 | 26 | 按工程填写 | 沿用已有值；未配置建议系统 1:1、不拖拽 | 可整体接受建议或指定修改 |
| splitDividerColor | 深浅色分割线 | 26 | 按工程填写 | 沿用已有值；未配置建议系统默认，按已有主题适配 | 可整体接受建议或指定修改 |
| enableInSplitScreen | 窗口分屏内启用 | 26 | 按工程填写 | 沿用已有值；未配置建议 false | 可整体接受建议或指定修改 |

字段的准确取值与冲突规则见 [配置说明](configuration.md)。清单可按关联字段合并展示，但不得遗漏适用的配置项。

## 启动流程的全屏页面

扫描启动链路时，主动识别开屏广告页、启动页和隐私协议页。核实其页面用途与实际路由标识后，默认加入 fullScreenPages，并在配置清单中列出页面及依据；这些已明确的接入规则无需逐页再询问是否全屏。其他用途的全屏页仍按业务需求确认，用户明确指定例外时遵循其选择。

Router 填写真实 pages 路径，Navigation 填写真实 NavDestination name。系统启动窗口、启动图、广告组件或隐私协议弹窗若没有独立路由页面，不能把组件名、资源名或弹窗标识填入 fullScreenPages，也不能为配置而新建页面或重构启动流程。若这类内容承载在普通业务页上，不自动将整个业务页全屏；说明实际承载方式，确需改变承载页行为时再确认。

与已有 fullScreenPages 合并去重，并核对本次启用的设备覆盖配置，避免 phone/tablet 替代 common 后漏配。若目标页已作为 homePage、relatedPage 或 transPages，不能重复写入冲突字段；说明冲突并确认主页/关联页或过渡页的调整，不静默改动原路由关系。动态路由标识尚未核实时保留待核实，继续追踪，不能编造或直接视为无需全屏。

## 集中确认与实施依据

优先确认尚未明确的模式、设备/窗口、主页/关联页、其他未明确的 fullScreenPages，以及购物模式的 transPages。提问附上候选页面及简短行为说明，支持多选、补充业务意图或选择“无需”；其他配置允许一次接受建议值。导航模式不询问购物专属 transPages。

“待确认”不等于空数组。用户未回复时不能自动接受建议，也不能把未决定的页面列表设为空。用户明确无需全屏页/额外过渡页后，才省略字段或使用空数组；用户明确接受整张清单、其中含明确的“无需”建议，也可作为确认。收到部分回答时只追问尚未解决的业务选择，不重复确认已决定项。

把确认后的值、页面用途与真实标识、版本选择作为本次方案和实施依据；沿用会话或已有方案记录，无需额外创建过程文件。配置未确认前可继续只读追踪页面与检查条件，不执行依赖该选择的写入。

## 接入默认值与升级

新接入默认 `enableReducedContainerSize: true`；API 26 同时默认 `drawableRectHook: true`。这是 Skill 接入默认值，官方两个字段的缺省值仍为 false。默认值不构成强制合法性要求，合法的 false 不应被静态校验判错。

API 23～25 工程优先建议将本机 SDK 与 compile 升到 26，以启用两个字段；保持 compatible，target 无独立要求时保留原值。用户确认升级前不改版本。用户选择保持旧版本时，仅开启 enableReducedContainerSize，省略 drawableRectHook 并说明限制。工程已有基础配置时，脚本的 requiredApi 可能仍是 23；AI 必须把计划新增的 drawableRectHook 纳入升级方案，不能仅依赖扫描结果。

用户明确选择 false 时直接遵循；既有配置显式 false 时保留，将与新接入默认值的差异列入清单，用户明确选择更改后才覆盖。设备覆盖配置分别执行此规则，不因默认值更新而改动用户范围外的设备配置。
