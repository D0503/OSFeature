# 握持手资产

使用 [HoldingHandSession.ets](../../assets/HoldingHandSession.ets)。构造参数为方向回调和错误码回调；`start()` 仅在目标可见且功能开启时调用。API/SysCap 不满足或订阅失败返回 false，调用方恢复原路径。

在应用关闭、页面隐藏/后台/销毁时调用 `stop()`，立即屏蔽迟到回调并恢复基线；退订失败保留订阅记录，不创建新实例反复 on。需要重试时由下一次明确的生命周期清理触发。

方向回调应复用组件当前状态：相同方向不重复动画，操作中先暂存最新方向，操作结束后再移位。错误回调清空待处理方向并恢复源基线；未知/双手/未握持由 Session 忽略。样例不创建业务控件，也不替调用方决定默认位置。
