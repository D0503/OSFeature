# 握持手验证

- API 19 及以下不执行 holdingHandChanged，API 20+ 核对 DETECT_GESTURE 和运行 SysCap；可调用不等于具体机型支持。
- 支持真机正常姿态下验证左、右、双手、未握持和 UNKNOWN_STATUS=16；设备非静止时未握持不保证识别，不把没有结果归因于应用缺陷。
- 排查时检查开关、亮屏解锁、壳厚、手套、掌心/手指接触、朝向及外物接触；模拟状态只用于 UI 分支测试。
- 页面反复进出、后台、订阅失败、退订失败、权限错误和 801 时不重复 on、不全局 off、不留下可见增强残留。
- 换手时按压中的按钮不移动，结束后仅应用有效方向；同一按钮不被操作手事件抢占。
- 执行 [共同矩阵](../../performance-validation.md)，记录实际事件、动画、原功能与回退表现。
