# 智感握姿自定义感知共同约束

- 仅页面可见且功能开启时启用；页面隐藏、后台、关闭或销毁时停止。按工程真实生命周期连接，`aboutToDisappear` 不覆盖所有“页面仍在组件树中但不可见”的情况。
- 保存稳定回调，以订阅成功标志避免重复 on。`motion.off` 也属于新接口调用：退订前先检查订阅成功标志，并确保调用处仍受所选路线的运行时 API 与 Motion SysCap 守卫保护；未成功订阅或版本/能力门禁不满足时不得直接调用。成功订阅后即使页面已隐藏、功能已关闭，也要在清理路径尝试用同一回调退订，不能再用“页面可见/功能开启”条件阻止 off。off(event) 不带回调会移除该事件所有监听，不作为可复用组件默认做法。
- 停止后忽略迟到回调；退订门禁意外不满足或 off 失败时保留订阅记录并报告，不能清空标志后再次 on 形成重复订阅。下一次显式生命周期清理可重试，不循环重试。
- 201、801、31500001/31500002 回退到原路径并记录诊断；31500003 为退订失败。操作手接口还可能有 401 参数错误。不持续弹错误窗，不自动改为另一种感知语义。
- 左/右状态去重再更新跟手目标的位置；未识别、双手、未握持或暂时无回调时保持当前侧。原组件位移模式初始位置取原布局，不统一默认右侧；新增模式的初始显示见[智感握姿跟手模式](follow-modes.md)。明确关闭时恢复原组件位置或撤去新增组件，已确认的接口错误按智感握姿 Skill 的「保留源程序状态」处理；无回调不能推断为关闭。
- 不移动正在按压、拖拽、滚动操作中的目标；暂存最后一个有效方向，交互结束且增强仍有效后再应用。关闭或错误时清除待应用方向，防止稍后恢复过期位移。
- 只建议对高频且单手难触达的操作组件接入；低频、非操作类组件和广告/诱导类按钮不建议接入。贴边组件从屏外绕到对侧，垂直高度不变、左右边距一致；底部/宽组件屏内整体平移，组内顺序和间距不变。
- 动画曲线优先使用官方推荐值：组件出场位移动画使用 `curves.interpolatingSpring(0, 1, 200, 17)`（stiffness=200，出场更利落）；从屏幕外移入/移出使用 `curves.interpolatingSpring(0, 1, 170, 17)`（stiffness=170，侧边绕行更自然）。不得使用未经验证的参数组合。
- 贴边组件采用条件分支做屏外进出场时，先取得实际布局宽度和接入前初始坐标，再显示目标分支；异步尺寸未就绪时不要用默认 `x=0` 渲染按钮或启动转场。左右分支各自保存响应式位置和 `START/END` 边，切换前只设置入场分支的目标位置与边，不提前改动退场分支。转场配置在实际按钮节点上，并核对其父容器覆盖预期可视宽度；不要用单个按钮的横坐标动画代替屏外进出场。
- 不在回调做重计算或重建业务状态。去重与动画合并依据项目实际交互实现，不强加固定 300ms 防抖；若动画使用条件渲染，业务数据和操作状态保存在原共享状态中。
