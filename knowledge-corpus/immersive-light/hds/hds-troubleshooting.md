# HDS 沉浸光感常见问题与处理

## 常见问题

| 现象 | 检查 | 处理 |
|---|---|---|
| HDS 效果过重或卡顿 | 自定义档位、设备支持类型、材质面积 | 改用 `ADAPTIVE`/`SMOOTH`，缩小区域 |
| Web 内嵌控件透明 | API 23 同层渲染 | 关闭控件光感或同层渲染 |
| 悬浮栏离底部过高或出现固定空白 | padding 的用途、组件层级及普通/悬浮分支，含默认栏间距 | 普通 Tab 导航条避让 padding 仅保留在普通分支；其他用途按实际布局判断，不机械清零 margin |
| 最后一项可见但无法完整点击，或被悬浮栏遮挡 | 每个滚动 Tab 的尾部空间 | 在最后一项后增加足够的 offset/占位/padding |
| 接入分支仍出现侧边 Tab | 方向、位置的断点条件及所属版本分支 | 接入分支统一底部横向；仅低版本保留原响应式布局 |
| 栏宽或文字异常 | 外层 barWidth 残留、字体倍率和多语言 | 删除接入分支外层栏宽，由 barFloatingStyle 的栏宽配置或默认行为生效，验证窗口矩阵 |
| 隐藏后仍占位 | `barHeight`、视觉位移和点击区域是否同步 | 同步布局高度、动画状态和热区 |
