# 沉浸光感悬浮 Tab 栏宽与断点

## 悬浮 Tab 栏宽与断点

- **悬浮 Tab 只按运行 API 区分升级接入分支与原代码保留分支，不按设备类型或断点分流。**HDS 达到 API 23、ArkUI 达到 API 26 时进入各自升级接入分支；不得附加 `isPhone`、`isTablet`、小屏等条件把其他设备送回原 Tabs。材质能力和关闭状态只控制升级分支内的材质回退，不决定组件树分支。
- 原代码保留分支只服务于未达到路线运行 API 门槛的情况；设备、断点、横竖屏和窗口适配由原代码继续负责，不重新设计设备分支。最低兼容版本已达到门槛时无需新增低版本分支。
- HDS 与 ArkUI 沉浸光感接入分支删除外层 `.barWidth(...)`，由 `barFloatingStyle.barWidth` 的配置或默认行为自动生效，不额外添加固定宽度。内容容器宽度和 MiniBar 布局单独处理。
- 所有断点、横竖屏和窗口尺寸均使用底部横向 Tab：`vertical(false)`、`BarPosition.End`。移除该分支的侧栏切换条件及专属布局配置，保留控制器、页签状态和业务事件。
- 仅低版本兼容分支保留接入前的侧边/底部响应式布局及栏宽。设备不支持或材质关闭时使用材质回退，仍保持底部 Tab，不恢复侧栏。
